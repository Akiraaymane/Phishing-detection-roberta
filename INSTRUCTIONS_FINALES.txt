## ORDRE D'EXECUTION RECOMMANDE

### Option 1: Workflow Automatisé (RECOMMANDE)

```bash
# Un seul script qui fait tout
python run_workflow.py --data_type sms --skip_cv

# Avec cross-validation (plus long)
python run_workflow.py --data_type sms

# Pour email
python run_workflow.py --data_type email --skip_cv
```

### Option 2: Exécution Manuelle

```bash
# 1. EDA (2-3 min)
python eda_analysis.py --data_type sms --data_path sms_spam.csv

# 2. Training Local (60 min)
python train.py --data_type sms --data_path sms_spam.csv --output_dir roberta-sms --epochs 2 --batch_size 16

# 3. Testing (5 min)
python test.py --data_type sms --data_path sms_spam.csv --model_path roberta-sms

# 4. Cross-Validation OPTIONNEL (180 min)
python cross_validation.py --data_type sms --data_path sms_spam.csv --n_splits 3 --epochs 1

# 5. Training Docker (70 min)
docker-compose up train-sms

# 6. Comparison (1 min)
python compare_environments.py --data_type sms

# 7. API Testing (1 min)
pytest test_api.py -v

# 8. Generate Report (1 min)
python generate_report.py
```
